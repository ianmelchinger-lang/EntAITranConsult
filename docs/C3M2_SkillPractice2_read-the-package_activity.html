Read what arrives with the data

Governed data meets four tests. Anyone downstream can trace it to its origin. Someone prepared and labeled it in a documented way. Someone checked it for gaps, meaning missing records, and for skews, meaning cases that are over- or under-represented. And it matches the context the system will run in, not only the context where it was collected. When a dataset arrives labeled ready, the documentation that comes with it shows how far the governance reaches.

A manufacturer’s quality function offers its supplier-quality records as ready. The records are supplier nonconformance write-ups held in the quality management system. They will feed a reader that surfaces exceptions in supplier documents at all nine plants. The package that came with the records has six passages.

For each test, judge what the package shows. Choose Shown when a passage shows the test was met. Choose Shown to fail when a passage shows it was not. Choose Not shown when nothing in the package speaks to it.

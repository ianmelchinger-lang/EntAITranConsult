Where did the saved time actually go?

A benefit that disappears from one step rarely disappears from the organization. It relocates — to a colleague, to a different function, to the customer, or, if nobody was named to catch it, nowhere at all. A value claim isn't finished until it says which.

Each of these four value claims looks like pure time saved on its own line. For each one, decide where the leftover checking, correcting, or waiting actually lands.

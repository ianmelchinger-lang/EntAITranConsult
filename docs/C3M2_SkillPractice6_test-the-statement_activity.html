Ask what it was tested against

A readiness assessment collects statements from the people who run the estate. Two kinds arrive, and they carry different weight. A self-report describes the speaker’s own work in general terms, such as “the platform can support this.” It is usually informed and honest, and it is evidence to test, not a finding to record. A finding comes out of a test, and the speaker can name it. One question separates the two: what did you test it against?

A manufacturer’s transformation team is assessing whether an assistant that drafts warranty responses can run on the consolidated data platform. It will read claim records from four regional systems. Six statements came in from three roles.

Each statement arrives with the answer the speaker gave when asked what they tested it against. Record a statement as a finding when the answer names a test run on this asset or this use. Mark it test against this use first when the answer is general capability, an impression, or a sample someone else chose.

One answer slot

The narrative spine is a four-part sequence that carries an executive account from the present to one recommendation: what is true now, what has changed to make that a problem, what question the change raises, and the single answer. Every source document has to serve one of the four, so no document argues its own case alongside the others. The answer slot holds exactly one answer. If two documents each demand a different action, the spine has not failed. It has found a disagreement the documents still carry.

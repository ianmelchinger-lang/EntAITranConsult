Find the pair

A paired quality metric is a measure attached to an efficiency measure because it would move the wrong way if the efficiency gain were an illusion. Speed and volume measures stop counting when work leaves the desk, so they report the same good news whether the work improved or only left sooner. Your job is to find where the work would come back.

A manufacturer is writing metric sets for four AI initiatives. Each set already holds one efficiency measure. For each, four companion measures have been proposed.

For each efficiency measure, choose the one companion that would move the wrong way if the gain were false.

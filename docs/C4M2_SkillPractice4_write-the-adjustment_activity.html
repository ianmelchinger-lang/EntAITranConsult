Check the mix, then write the adjustment

A default allocation split is a commonly cited starting reference for how much investment weight sits in the near, mid, and longer lanes. It is a reference point, not a validated target. The right balance shifts with how mature the industry is and how fast disruption is moving through it, and a mix judged against an unadjusted default is judged against somebody else’s industry.

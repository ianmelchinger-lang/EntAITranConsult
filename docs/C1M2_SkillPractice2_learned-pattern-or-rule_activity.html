Pass the gate, find the zone

One question decides whether something belongs on the map at all. A second decides where.

Before anything counts as AI capability, it has to pass one test: does it act on patterns learned from data, or does it execute a rule someone wrote by hand? A fixed rule, however it's marketed, doesn't pass.

Whatever does pass lands in one of four nested zones. Machine learning sits at the center. Deep learning is a more specialized form of it, built for messier inputs like images. Generative capability is built on deep learning and produces new content — a document, a response — rather than only classifying what it's shown. Agentic capability sits alongside it, distinguished not by more intelligence but by more authority: how much it can do without a person approving each step.

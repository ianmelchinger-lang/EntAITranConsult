Run the gate before anything scales

The pilot-to-scale gate is the set of checks an initiative clears before it moves from pilot status to funded, scaled standing. Four checkpoints and a fixed baseline are used here: a stated link to strategic goals, an interoperable technical foundation, a trained and available team, a compliant and transparent operating practice, and a fixed measurement baseline. They are the checks used here, not a complete list of everything a scale decision could need.

A service team built a drafting tool on its own, and it spread. teams and users now use it, at about sessions per user per week. Its sponsor asks for scaled funding. The lines under each checkpoint are everything on file.

For each checkpoint, decide whether the evidence on file answers its question with a yes. Cleared means it does. Not cleared means it does not, or the evidence does not speak to the question. Then give a verdict.

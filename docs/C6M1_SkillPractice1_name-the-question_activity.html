Name the question first

Three kinds of instrument are all called an AI governance framework, and each answers a different question. A voluntary risk framework answers how an organization should think about AI risk. A certifiable management-system standard answers whether the organization runs AI governance as a repeatable internal system that an outside auditor can certify. Binding law answers what is legally required, of whom, and at what level of risk. Pick an instrument before you know the question, and the client builds the wrong thing well.

Leaders at a manufacturer have each asked the advisor for help with AI governance. None of them names an instrument.

For each request, decide which question it carries. There are four places to put it.

Risk framework: how should we think about AI risk?

Certifiable system: do we run governance as a system an auditor can certify?

Binding law: what does the law require of us?

Ask which question: the request carries no single question yet, so the move is to ask.

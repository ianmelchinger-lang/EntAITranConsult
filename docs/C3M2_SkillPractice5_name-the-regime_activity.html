Name the regime, then give the reason

When a client’s data is fragmented and partly ungoverned, two positions are defensible. Govern in place means building governance, access control, and permission around the data where it already lives. Foundations first means building a common architecture, with one agreed source per domain, before the use case runs. Both sides accept the same test: whether governance fits the target use case. So the regime follows the use case. Bounded, lower-stakes work proceeds on data governed in place. Automation running on core, regulated, cross-domain data at scale needs the foundations first.

A manufacturer’s transformation team has three use cases in front of it. Each card lists five facts. The finding for each one names a regime and the two facts of scope and stakes that put it there.

For each use case, choose a regime and check exactly two facts. Scope is how far the use case runs. Stakes are what a wrong output costs.

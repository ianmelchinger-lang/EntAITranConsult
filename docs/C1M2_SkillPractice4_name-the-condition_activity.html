Name the condition

The same word, “gap,” hides three different problems, and only one of them gets fixed by buying something.

A shortfall is always in one of three conditions, and they don't overlap. It can be absent — it doesn't exist yet. It can exist and underperform — it runs, but falls short. Or it can exist and perform well while sitting outside any oversight check. Each condition takes a different fix: build or buy for an absence, improve the model, the data, or the process for underperformance, add a reviewer or an approval path for a missing check.

For each shortfall below, name its condition, then choose the remedy that actually follows from it.

Answer both parts of every shortfall before checking — its condition, and the remedy that follows from it.

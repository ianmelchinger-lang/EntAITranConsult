What the silence shows

Risk is a condition, not a property. It changes as the system, its data, its users, and its uses change, so a launch sign-off describes the system that shipped and nothing after it. Evidence about a running system is useful only if it would read differently when the system is failing. Evidence that reads the same either way shows nothing, and silence from users shows only that nobody has complained yet.

Six months after launch, the function head says the customer-exception workflow is working.

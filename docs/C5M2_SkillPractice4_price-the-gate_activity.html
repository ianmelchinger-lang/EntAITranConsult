Price the gate

Gate placement is the decision about where human review sits in an automated workflow. Each position trades safety against speed, and each buys a different amount of review work. In a return-on-investment model that work is a cost line: the items that stop for a person, multiplied by the time one review takes.

A manufacturer’s service function runs a workflow that answers customer requests for exceptions to warranty terms. It classifies each request, writes the reply, sends it, and updates the record, 1,150 requests a week. No one reviews a reply before it goes.

The function now wants a review gate and is weighing three placements. The review times and the trigger share are illustrative.

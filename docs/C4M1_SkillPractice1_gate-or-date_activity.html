Gate or date?

A phase gate is the boundary between two phases, written as a condition that has to be true before the next one begins. A gate names a fact a second person could check and answer yes or no. A date can only be waited for.

A transformation team has drafted the boundary for six initiatives. Some name a fact someone could go verify. Others name only a date, or a feeling.

Real, fundable, both, or neither yet?

Bottom-up discovery finds what is real. Top-down discovery finds what is fundable. A candidate that has passed only one of those two tests is probably not ready yet — and that's a finding, not a failure of the search.

For each candidate, ask both questions separately: would the person doing the work confirm this is real, and can a budget-holder name the value in the business's own terms? Sort each one by what it's actually passed.

One thing moves

A planner on the supply-chain team is asked directly about the visibility priority, and confirms: yes, this is what eats her week. That one conversation moves the third candidate into the ready quadrant — the top-down case didn't change at all. That's the whole value of running both tests separately: each one can close on its own, whenever the missing evidence actually shows up.

Find the stratum

Two tools can share a license count and still be doing completely different amounts of work.

Placement in a zone says what a system is. It doesn't say how much of the actual work it's taken over, and a map needs both readings. At the first stratum, a person brings the problem and the tool works as a turn-taking thought partner. At the second, a validated problem is handed to a configured workflow that runs it end to end. At the third, the workflow itself is designed around AI, with systems passing work to each other directly.

For each system below, choose the stratum its actual use describes — not the stratum its scale or its license count might suggest.

Correct the fact or answer the change

A wrong assumption is a fact the plan relied on that was never true, and it gets a correction. A fragile dependency is a fact that is true today and may stop being true before the plan finishes, and it gets an answer: something the plan does if the fact changes. Mix them up and the effort lands on the wrong target.

A reviewer who did not write a manufacturer’s eighteen-month roadmap has collected six concerns. Each card gives the fact the plan relies on, where that fact stands today, and what the plan says if it changes.

Sort each concern into one of three places.

Wrong assumption. Correct the fact, then adjust what rested on it.

Fragile dependency. Add an answer. A fallback takes over if the fact changes. A trigger signals that it has moved. A resequencing takes the work off the path that sets the finish date. Removing the initiative is also an answer, when it is not worth the exposure.

Already answered. The plan already says what happens if the fact changes, so the concern needs no finding.

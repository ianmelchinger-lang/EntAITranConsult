Who is at the gate?

The portfolio gate is the point where portfolio criteria start to apply to a build: when it asks to scale, asks for funding, or someone proposes ending it. Before that point, a build is an experiment, recorded in the log but not judged. Apply the criteria too early and people stop experimenting. Never apply them and the organization funds parallel builds indefinitely.

A manufacturer's intake log holds seven running AI builds. The steering group has time to judge only the ones that belong in front of it this cycle.

For each build, decide whether it faces the portfolio criteria now or stays in the log as an experiment.

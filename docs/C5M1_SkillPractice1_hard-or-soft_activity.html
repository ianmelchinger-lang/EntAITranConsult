Hard or soft

A return is a benefit a case counts in money. A hard return converts directly into cash: it removes a cost or adds revenue that appears on a financial statement, with no estimate standing between the event and the number. A soft return has a real financial effect, but no statement records it directly, so the case must carry an estimate and someone must defend it. Observability decides the grade. Size does not.

A manufacturer’s quality organization has a draft case for a system that reads supplier quality documents. The case lists six benefits. Every figure on this page is illustrative.

Ask one question of each benefit: a year from now, could a reviewer confirm it on a financial statement, or would the reviewer have to rely on an estimate?

Mark it hard if the statement would show it. Mark it soft if only an estimate could.

What the case may say

A hard return can be asserted, because a reviewer can check it against its line after the fact.

    A soft return should be presented as an estimate, with the reasoning shown. The estimate behind each is the thing a reviewer will ask about.

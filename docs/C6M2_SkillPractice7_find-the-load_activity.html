Find the load

Detectability is how hard an error is to see in the output, given what the reviewer has in front of them, and a plan sets it through how the review is built. A review that needs real minutes for each item, at a volume those minutes cannot fit, fails by construction before anyone asks how diligent the reviewer is. The arithmetic comes first: items, times minutes, against hours.

A manufacturer’s scheduling assistant writes the maintenance work-order schedule for each plant, and one named reviewer reads it before release. It runs at two sites today. The plan extends it to seven and keeps the one reviewer. A review that can actually catch an error means reading each schedule entry back against the work order and equipment records, with those sources beside it.

Second pass: narrow the check

Suppose the review is redesigned. The source material sits beside each schedule, and the reviewer checks only the claims where unsupported content clusters: specific figures, statements that depend on recency, and references to the organization’s own material. Nothing else changes. Choose how long a narrowed check takes. This is an assumption for the exercise, not a measured figure.

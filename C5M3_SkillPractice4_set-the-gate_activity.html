Set the gate

An adoption gate is a threshold of real use that an initiative must pass before anyone reads its value metrics. An activity metric describes behavior around a tool. A value metric describes a change in a business outcome. Below the gate, a value metric can’t yet say anything about the tool, in either direction.

A manufacturer’s service and warranty operation gave an AI drafting assistant to 96 people in seven teams. The measurement plan sets the gate at 60 percent: a team’s handling time counts as evidence about the assistant only once 60 percent of the team uses it every week. The table shows each team at the end of the first quarter. A change smaller than half a minute is within the queue’s ordinary swing, and the review calls it flat.
